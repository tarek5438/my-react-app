# منصة ميثاق ود - لتسجيل وتنظيم وبحث استمارات الزواج (React + Vite + Tailwind CSS)

## طرق التشغيل على جهازك:

### الطريقة الأولى: تشغيل فوري بضغطة واحدة (بدون تثبيت أي برامج)
افتح ملف `mithaq_wad_standalone.html` مباشرة في أي متصفح (Chrome / Edge / Firefox) وسيعمل معك الموقع بكامل مميزاته فوراً.

### الطريقة الثانية: تشغيل كمشروع React كامل للتطوير (VS Code / Node.js)
1. تأكد من تثبيت [Node.js](https://nodejs.org/) على جهازك.
2. فك الضغط عن مجلد المشروع وافتحه في VS Code أو موجه الأوامر (Terminal).
3. نفّذ الأمر التالي لتثبيت الحزم:
   ```bash
   npm install
   ```
4. شغّل السيرفر المحلي:
   ```bash
   npm run dev
   ```
5. افتح الرابط الذي سيظهر لك (عادةً `http://localhost:5173`).

- **رمز دخول لوحة الإدارة التجريبي:** `1234`
